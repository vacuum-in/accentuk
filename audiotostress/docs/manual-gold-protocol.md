# Manual ambiguous-stress protocol

Annotate naturally occurring ambiguous forms only after listening to the target occurrence in context.
Record the normalized target, selected vowel index, source/utterance/record IDs, original and normalized
context, annotator ID, and annotation version. Validate every selected index against the versioned lexicon.

For controlled recordings, collect both readings of each ambiguous form from every speaker where practical,
randomize prompt order, and retain speaker IDs only for leakage-safe evaluation and balance checks.
